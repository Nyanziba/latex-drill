# 上級 a01: 再利用できるコマンドと環境

## この課題で身につけること

文書中で何度も使う表示を、引数付きのコマンドと環境に切り分けます。書式を一か所で管理し、本文では「何を示すか」を読みやすく表せる状態を目指します。

## 公式資料を読む

LaTeX Project の「著者のための LaTeX（最新版）」は、文書作成者がコマンドや環境を作るときのインターフェースを扱います。第2章では引数仕様を宣言してから実装を与える考え方を説明し、必須引数には m を使います。環境は開始時と終了時に行う処理を分けて定義できます。詳しい低水準の実装資料として interface3 も案内されています。

この資料は LaTeX 初心者向けの入門書ではなく、文書作成者向けの機能リファレンスです。最初から全機能を読むのではなく、第2章のコマンド・環境作成に絞って参照してください。

## 課題

exercises/a01/main.tex を完成させ、upLaTeX で処理できる jlreq 文書にしてください。新しいパッケージは読み込まず、次の公開インターフェースを作ります。

1. DrillTerm は必須引数を1つ受け取り、「用語：」に続けて引数を強調表示する。
2. drillnote 環境は必須のタイトル引数を1つ受け取り、開始時にタイトルを見出しとして表示する。環境本文の後に段落を適切に閉じる。
3. 本文で DrillTerm を複数回、drillnote を少なくとも1回使用する。定義だけでなく、利用例まで確認できる文書にする。

本文の文字装飾や環境の間隔は読みやすい範囲で決めてください。引数の受け取り方と、本文での呼び方が対応していることが重要です。

## 自己採点

- 文書クラスが jlreq で、コードが main.tex にまとまっている。
- DrillTerm は NewDocumentCommand で定義し、引数仕様 m を宣言している。
- drillnote は NewDocumentEnvironment で定義し、タイトルを引数として受け取っている。
- 本文で両方のインターフェースを使っている。
- TODO と「I AM NOT DONE」マーカーを解消した。

この drill の標準処理系は upLaTeX と dvipdfmx です。コンパイルする場合は uplatex で DVI を作成し、dvipdfmx で PDF に変換します。

## ヒント

コマンド定義では、引数仕様と置換後の本体を別々に読んでください。環境定義では開始側でタイトルを出し、終了側で本文の段落を閉じると、利用する側が見出しの書式を毎回書かずに済みます。
