# 上級 a02: 小さな .sty パッケージを作る

## この課題で身につけること

文書固有の定義を別ファイルにまとめ、他の文書からパッケージとして読み込みます。パッケージの識別情報、利用者向けの公開インターフェース、文書側での利用をひと続きで練習します。

## 公式資料を読む

LaTeX Project の「LaTeX for class and package authors」は、クラスやパッケージを作る人向けの資料です。構成の説明では、ファイルの識別、必要な準備、オプション、追加定義という段階を整理しています。パッケージファイルでは ProvidesPackage で自分を識別し、本文側から usepackage で読み込みます。資料は、単純なケースには newcommand や newenvironment などの定義インターフェースを使うことも勧めています。

これは初心者向けチュートリアルではなく、著者やパッケージ開発者向けのリファレンスです。ここでは依存管理や複雑なオプション処理には踏み込まず、パッケージの基本構造に絞ります。

## 課題

exercises/a02 に main.tex と drillbrand.sty を作成してください。新しい依存パッケージは使わず、次の機能を drillbrand.sty にまとめます。

1. パッケージ名を drillbrand として識別する。
2. DrillBadge は必須引数を1つ受け取り、引数を角括弧付きの sans-serif 体で表示する。
3. drillquote 環境は本文を quote 環境に入れ、小さめの文字で表示する。
4. main.tex は drillbrand を読み込み、両方の公開機能を本文で使う。

パッケージファイルは main.tex と同じディレクトリに置きます。利用者向けの定義を .sty に集め、文書側では読み込みと利用例に専念してください。

## 自己採点

- main.tex の文書クラスは jlreq である。
- drillbrand.sty が LaTeX2e の形式を要求し、ProvidesPackage で自身を識別している。
- DrillBadge と drillquote の定義が drillbrand.sty にある。
- main.tex が drillbrand を読み込み、コマンドと環境の両方を使っている。
- drillbrand.sty と main.tex に未解決の TODO や「I AM NOT DONE」マーカーがない。

この drill の標準処理系は upLaTeX と dvipdfmx です。コンパイルする場合は uplatex で DVI を作成し、dvipdfmx で PDF に変換します。

## ヒント

パッケージの最初の識別行は、利用者がファイルの役割を把握し、LaTeX がファイル情報を記録するためのものです。今回の機能は基本命令だけで書けるため、パッケージ内で別のパッケージを読み込む必要はありません。
