# 上級 a03: expl3 の変数と関数で状態を扱う

## この課題で身につけること

expl3 の token list 変数に文字列を保存し、値を更新する関数と値を取り出す関数を作ります。その上に通常の文書向けコマンドを置き、実装の詳細と本文の利用方法を分離します。

## 公式資料を読む

LaTeX Project の著者向け現行ガイドは、安定して広く利用できる文書作成機能を扱い、より技術的な expl3 の仕様を interface3 に案内しています。クラス・パッケージ著者向けガイドも、L3 プログラミング層には公開 API と内部専用の関数があると説明しています。interface3 は公開関数の命名、型、引数仕様を確認するリファレンスです。

これらは初心者向け教材ではなく、文書作成者・パッケージ開発者向けの資料です。expl3 の全機能を覚えるのではなく、この課題で使う token list 変数と関数定義の項目を引いてください。LaTeX Project の公式ドキュメント一覧から L3 programming layer interface documentation に進めます。

## 課題

exercises/a03/main.tex の未完成部分を埋めてください。新しいパッケージは追加せず、expl3 を使って次の公開インターフェースを実装します。

1. g_latexdrill_topic_tl という大域 token list 変数を宣言する。
2. latexdrill_set_topic:n は引数1つを変数に保存する保護された関数とする。
3. latexdrill_print_topic: は変数の現在値を返す関数とする。
4. DrillSetTopic と DrillPrintTopic の2つを文書向けコマンドとして公開する。
5. 本文で値を設定し、表示し、別の値に更新してからもう一度表示する。

expl3 の定義と文書向けコマンドの両方が解決されるよう、名前に _ や : を含むコード範囲を ExplSyntaxOn と ExplSyntaxOff で囲みます。日本語の値を使い、保存した値が本文に反映されることを確かめる構成にしてください。

## 自己採点

- 文書クラスが jlreq である。
- token list 変数が型付きの命名で宣言されている。
- setter 関数が引数を受け取って変数を更新し、printer 関数が現在値を参照する。
- 文書向けの2コマンドから expl3 関数を呼び出している。
- 本文で更新前と更新後の値をそれぞれ表示する。
- expl3 の範囲を開始・終了する指定が対になっており、TODO と「I AM NOT DONE」マーカーを解消した。

この drill の標準処理系は upLaTeX と dvipdfmx です。コンパイルする場合は uplatex で DVI を作成し、dvipdfmx で PDF に変換します。

## ヒント

interface3 で tl 型の作成・設定・利用の関数を探してください。変数名の型サフィックスと、関数名の引数形サフィックスを照合すると、各命令の役割を追いやすくなります。本文向けコマンドは、内部関数に引数を渡す薄い入口として定義できます。
