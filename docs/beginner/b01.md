# b01 最小の和文文書構造

## このドリルで身につけること

最小の和文LaTeX文書を、文書クラス・本文開始・本文終了の順で組み立てます。本文は2段落に分けます。

## 読み物

LaTeXのソースには、本文の文章と、文書の構造を表す命令が並びます。命令はバックスラッシュ `\` で始まり、必要に応じて波括弧 `{}` で引数を受け取ります。

文書の先頭では `\documentclass{jlreq}` によって和文組版向けの文書クラスを選びます。`jlreq` は upLaTeX に対応する汎用和文クラスです。続くプリアンブルには設定を書き、`\begin{document}` から `\end{document}` までを本文として扱います。本文の外に文章を置くと、通常の文書本文にはなりません。

本文の段落は、ソース上に空行を入れて区切ります。行を変えただけでは段落が分かれない点に注意してください。ソースに付ける `%` から行末までのコメントは、PDFには出力されません。

このドリルでは upLaTeX を使います。upLaTeXはDVIを生成するエンジンなので、PDFが必要な環境では `dvipdfmx` でDVIを変換します。課題には図やリンク用パッケージを使わないため、最小例の文書クラス指定は `\documentclass{jlreq}` とします。

## 課題

`exercises/b01/main.tex` を編集してください。文書クラスに `jlreq` を指定し、本文の開始・終了を記述します。その間に、次の本文を指定された順に2つの段落として入れます。

1. `LaTeXで和文文書を作ります。`
2. 空行を挟み、`段落は空行で分けます。`

`% I AM NOT DONE` とTODOコメントを解消してください。

## 自己採点

- [ ] 文書クラスは `jlreq` である。
- [ ] 本文は `\begin{document}` と `\end{document}` の間にある。
- [ ] 指定された2つの文が、空行で分かれた別段落になっている。
- [ ] `main.tex` に `% I AM NOT DONE` が残っていない。

## つまずいたとき

- `\begin` や `\end` のエラー: 波括弧や環境名の綴り、開始と終了の順序を見直します。
- 和文クラスが見つからないエラー: TeX Liveの和文関連パッケージが導入された環境か確認します。
- PDFができない: upLaTeXの後に `dvipdfmx main.dvi` を実行する設定になっているか確認します。
