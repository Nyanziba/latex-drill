# b02 論理構造・強調・リスト

## このドリルで身につけること

見出しや強調、箇条書きを、見た目ではなく文書内での役割に合わせて記述します。

## 読み物

LaTeXでは、文字を大きくする、太字にする、といった見た目を直接指定するより、文章が見出しなのか、強調なのか、リスト項目なのかを表す命令を使います。役割を示しておけば、文書全体の体裁を後から整えるときに一貫性を保ちやすくなります。

節見出しには `\section{...}`、その下の小見出しには `\subsection{...}` を使います。これらは見出し番号や前後の余白などもクラスに任せます。強調したい語句は `\emph{...}` で囲みます。これは「強調する」という意味を記録する命令で、出力の書体は文書クラスや日本語・欧文の組版設定で異なることがあります。

順番が意味を持つ項目には `enumerate` 環境、順番を持たない項目には `itemize` 環境を使います。それぞれの環境の内側に `\item` を置くと、新しい項目が始まります。環境は `\begin{...}` と `\end{...}` を対にして閉じます。

## 課題

`exercises/b02/main.tex` を編集し、本文に次の構造を作ってください。

1. `文書の構造` という `\section` 見出し。
2. `強調` という `\subsection` 見出しの下に、`大切` を `\emph` で強調した短文。
3. `手順` という `\subsection` 見出しの下に、順序付きリストを2項目作る。項目は `設定を確認する。` と `本文を組み立てる。`。
4. `道具` という `\subsection` 見出しの下に、順序なしリストを2項目作る。項目は `エディタ` と `TeX環境`。

各リストの項目には `\item` を使い、環境を正しく閉じます。`% I AM NOT DONE` とTODOコメントを解消してください。

## 自己採点

- [ ] 大見出しと小見出しを、それぞれ `\section` と `\subsection` で作った。
- [ ] 強調語句を `\emph{...}` で囲んだ。
- [ ] 番号付きリストを `enumerate`、番号なしリストを `itemize` で作った。
- [ ] 各リスト項目に `\item` を置き、開始と終了の環境名が一致している。
- [ ] `main.tex` に `% I AM NOT DONE` が残っていない。

## つまずいたとき

- `\emph` のエラー: 強調する語句を `{` と `}` で囲み、両方の括弧があるか確認します。
- `\item` が使えないエラー: `\item` が `enumerate` または `itemize` の内側にあるか確認します。
- `\begin` / `\end` のエラー: `enumerate` と `itemize` を混同せず、開始と同じ環境名で閉じます。
