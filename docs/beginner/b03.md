# b03 数式モードと基本数式

## このドリルで身につけること

本文中の短い式と、独立した行に置く式を使い分け、添字と分数を記述します。

## 読み物

LaTeXでは数式は数式モードの中に記述します。本文の流れに含める短い式は `$...$` で囲みます。式を独立した行として見せる場合は `\[...\]` を使います。後者は段落中の空行に置かず、開きと閉じの記号を対にします。

数式モードでは、普通の文章の空白や文字の扱いとは異なります。変数は通常数式用の字体になり、演算子まわりの間隔も数式として整えられます。文字の上付きには `^`、下付きには `_` を使い、複数文字の添字・指数は `{...}` にまとめます。たとえば `a_{n}` は `a` に `n` を添字として付けます。

分数は `\frac{分子}{分母}` の形で入力します。`\frac` は分数を組む命令なので、スラッシュを使った文章表現とは異なる組版になります。初級では複数行の数式や追加パッケージに進まず、インライン式と別行立て式の違いを確実にします。

## つまずいたとき

- `Missing $ inserted` など数式モードのエラー: `$` の数、または `\[` と `\]` の対応を確認します。
- 添字や分数の表示が崩れる: `_` の直後や `\frac` の各引数が波括弧で閉じているか確認します。
- 文字間隔が思った通りでない: 数式モード内の空白は通常の文章と同じ意味を持たないため、式の構造で書けているか確認します。
