# i01 図と表を読みやすく配置する

## この課題で身につけること

図や表を文章の一部として流し込むのではなく、独立した番号付きの要素として作り、説明文とセットにします。LaTeXはページの空き具合を見ながら図表の位置を調整するため、配置指定は「ここに必ず置く」という命令ではなく、候補を伝えるものです。

## 図はfigure、表はtable

画像や図を`figure`、表を`table`の中に置くと、LaTeXがそれぞれをフロートとして扱います。`[tb]`はページ上部または下部を配置候補にする指定です。候補が合わない場合、実際の位置はソース上の位置と異なることがあります。

キャプションは`\caption{...}`で付けます。`\centering`はフロート内の内容を中央に寄せます。外部画像を使う場合は`graphicx`を読み込み、`\includegraphics[width=...]{ファイル名}`を使います。この練習では外部ファイルに依存しないよう、図の枠を`picture`環境で描きます。

## 表の列と罫線

`tabular`の列指定は、表の列数と揃え方を宣言します。`l`は左、`c`は中央、`r`は右揃えです。行のセルは`&`で分け、行末には`\\`を置きます。数値を右揃えにすると桁を比べやすくなります。

この課題では`booktabs`の`\toprule`、`\midrule`、`\bottomrule`を使い、表全体を縦線で囲わずに見出しとデータを分けます。列数、行のセル数、罫線コマンドの位置がずれると表が崩れたり、コンパイルエラーになったりするので、各行を見比べてください。

## 課題

`exercises/i01/main.tex`を完成させてください。

1. `figure`環境を作り、模式図を中央に置きます。配置候補は`[tb]`にします。
2. 図に「センサー配置」というキャプションと`fig:layout`ラベルを付けます。
3. `table`環境に、測定条件、平均値、試行回数の3列を持つ表を作ります。
4. 表に「測定ログ」というキャプションと`tab:measurements`ラベルを付けます。見出しとデータを罫線で区別します。

完成したら、図のキャプションが図の説明になっているか、表の各行が3列で揃っているかを確認します。ラベルを付けただけでは本文に参照文は加わりません。この課題では番号付きの図表を作るところまでを扱います。

## 自己採点

- 図と表はそれぞれ別のフロート環境に入っていますか。
- キャプションは対象と同じ環境内にあり、各ラベルは対応するキャプションの後にありますか。
- `tabular`の列指定は3列で、すべての行のセル数も一致していますか。
- `[tb]`を配置候補として理解し、出力位置が必ずソース位置になると考えていませんか。
