# i02 ラベルと相互参照を解決する

## この課題で身につけること

節や数式の番号を本文へ直接書くと、途中に要素を追加したときに番号の修正漏れが起きます。番号付き要素に`\label{...}`を付け、本文で`\ref{...}`を使えば、番号の決定をLaTeXに任せられます。

## ラベルを置く場所

ラベル名は著者が決めるキーです。`sec:measurement`や`eq:mean`のように種類を表す接頭辞を付けると管理しやすくなります。接頭辞の意味をLaTeXが解釈するわけではなく、同じ文書内でキーが重複しないことが重要です。

`\label`は直前の番号付き要素の番号を記録します。節なら見出しの直後、式なら`equation`環境の中で式番号が決まった後に置きます。図表の場合はキャプションが番号を進めるため、ラベルをキャプションより前に置くと別の番号を拾うおそれがあります。

## なぜ再コンパイルが必要か

LaTeXはラベル情報を補助ファイルに書き出し、その情報を次の実行で`\ref`へ反映します。そのため、初回の出力では参照が`??`になることがあります。参照元と参照先が正しいのに未解決表示が残る場合は、同じ文書をもう一度upLaTeXで処理します。構成を変えた後も、参照が落ち着くまで再実行が必要になることがあります。

## 課題

`exercises/i02/main.tex`を完成させてください。

1. 「測定方法」節に`sec:measurement`ラベルを付けます。
2. 平均値を表す番号付き式を`equation`環境で書き、`eq:mean`ラベルを環境内に置きます。
3. 本文で節と式をそれぞれ`\ref`で参照します。数字を本文に直書きしないでください。
4. upLaTeXで少なくとも2回処理し、参照番号が解決したことを確認します。

## 自己採点

- 節ラベルと式ラベルは、参照先の対象と正確に同じキーですか。
- 式ラベルは番号付きの`equation`環境内に置かれていますか。
- 本文には節・式の両方の`\ref`がありますか。
- 参照先を追加・変更した後、補助ファイルを更新する再コンパイルをしましたか。
