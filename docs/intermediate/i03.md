# i03 引用と参考文献を文書内で管理する

## この課題で身につけること

引用の記号だけを本文に書いても、出典が追跡できなければ読者は資料を確認できません。本文の引用キーと参考文献項目を対応させ、どの情報に基づいて書いたかを示します。

## 小さな文書ではthebibliographyを使う

LaTeXには、参考文献の項目を文書内に直接書く`thebibliography`環境があります。各項目は`\bibitem{キー}`で始まり、本文では同じキーを`\cite{キー}`に渡します。LaTeXが引用番号を付けるので、順序が変わっても本文中の番号を手で直す必要がありません。

この練習では文献数を少なくし、外部データベースやBibTeX等の処理ツールを使わずに、文書内の対応関係を学びます。文献が増える・複数文書で再利用する・引用形式の規則が細かい場合には、データベースと専用ツールを使う方法が向いています。どの方法でも、書誌情報の正確さを確認する必要があります。

## 課題

`exercises/i03/main.tex`を完成させてください。

1. 本文の「文献を示す」の箇所で、キー`learnlatex12`を使って引用します。
2. 文書末尾に`thebibliography`環境を追加します。
3. `\bibitem{learnlatex12}`を作り、コース名と参照したレッスンを記録します。
4. 外部の`.bib`ファイルやBibTeX/Biberを追加せず、文書内の引用と参考文献だけで完結させます。

## 自己採点

- 本文の`\cite`と`\bibitem`のキーは一字一句一致していますか。
- 引用を置いた文の根拠が、対応する項目の資料内容と結びついていますか。
- 参考文献環境は本文の後にあり、開始と終了が対になっていますか。
- 項目にコース名と参照したレッスンが記録されていますか。
